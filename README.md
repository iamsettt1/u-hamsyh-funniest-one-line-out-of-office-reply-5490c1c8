## The entry

> I'm away until Monday. My inbox is home alone and has already eaten two urgent emails — send snacks, not deadlines.

One line, and it does the whole job of an out-of-office reply: it says when I'm back, and it turns the usual "limited access to email" line on its head — the inbox isn't waiting patiently, it's unsupervised, hungry, and already misbehaving. No setup, no signature needed, nothing to explain afterwards.

## Run it

```sh
python3 main.py
```

It prints the reply and writes the same line to `/output/entry.txt`.
